# macos-mscp-scan v0.1.0

Initial public release of a read-only NIST mSCP CIS audit wrapper.

This release uses the original single-phase flow. The two-phase AI/user
handoff, reusable cache and stable report pointers documented for current
source are not part of v0.1.0.

## Included

- `scan_cis.zsh` — CIS Level 1 or Level 2 audit wrapper.
- `SHA256SUMS` and `SHA256SUMS.sig` — integrity manifest and detached SSH
  signature.
- `r4kh1m-release-signing-key.pub` — public key for manifest verification.

The release-signing key fingerprint is:

```text
SHA256:Rt9xlHKnOMVeREiwG041268qY0kxu72vYVt+CntuF+4
```

## Compatibility

macOS 14, 15, and 26 are accepted. The release was end-to-end tested on macOS
26 Apple Silicon. See [Compatibility](../compatibility.md) before using it on a
different target.

## Safety contract

The generated mSCP audit is invoked only with `--check`. This release does not
run remediation commands.

## Download and verify

Copy this complete block into a terminal. It downloads the release into a
unique `/tmp` directory, verifies both the SHA-256 manifest and detached SSH
signature, runs Level 1, and deletes only the downloaded release files on exit.
The audit report remains in the separate path printed by v0.1.0.

```zsh
(
  set -e
  work_dir="$(mktemp -d /tmp/macos-mscp-scan-v0.1.0.XXXXXX)"
  trap 'rm -rf "$work_dir"' EXIT
  cd "$work_dir"

  curl -fLO https://github.com/r4kh1m/macos-mscp-scan/releases/download/v0.1.0/scan_cis.zsh
  curl -fLO https://github.com/r4kh1m/macos-mscp-scan/releases/download/v0.1.0/SHA256SUMS
  curl -fLO https://github.com/r4kh1m/macos-mscp-scan/releases/download/v0.1.0/SHA256SUMS.sig
  curl -fLO https://github.com/r4kh1m/macos-mscp-scan/releases/download/v0.1.0/r4kh1m-release-signing-key.pub

  shasum -a 256 -c SHA256SUMS
  {
    printf 'r4kh1m-release namespaces="file" '
    cat r4kh1m-release-signing-key.pub
  } > allowed_signers
  ssh-keygen -Y verify -f allowed_signers -I r4kh1m-release -n file -s SHA256SUMS.sig < SHA256SUMS

  zsh scan_cis.zsh --baseline cis_lvl1
)
```
